## 安装&更新
在Yunzai根目录运行命令
```
git clone https://gitee.com/Tloml-Starry/Tlon-Sky.git ./plugins/Tlon-Sky/
```

如何更新？
 - 使用Yunzai自带指令`#全部更新`或指令`#光遇更新`
 - 运行`UPDATE.bat`文件，位置在`插件目录`内

## 功能
发送`光遇菜单`或`光遇娱乐菜单`查看

### 🌟 蜡烛记录功能
记录蜡烛数据，支持多账号管理，自动计算变化量。

**命令：**
- `#记录蜡烛<白蜡>:<季蜡>:<爱心>:<红蜡>` - 记录数据
- `#蜡烛记录` - 查看最近记录
- `#蜡烛ID列表` - 查看所有ID
- `#添加蜡烛ID <名称>` - 添加ID
- `#切换蜡烛ID <名称>` - 切换ID
- `#删除蜡烛ID <名称>` - 删除ID
- `#蜡烛记录帮助` - 查看使用说明

#### <div align="center">安装</div>
<div align="center">使用Gitee安装，在Yunzai-Bot根目录执行</div>

```
git clone https://gitee.com/Tloml-Starry/Tlon-Sky.git ./plugins/Tlon-Sky/
```

#### 绘画分享图库安装

* 使用指令：`Sky更新图库`
* 后续更新图库同上

config/config/ 说明
============================================
本目录(cron.yaml / push.yaml / text.json / kevcore.yaml /
光翼查询.yaml / 国服礼包查询.yaml 等) 是每台服务器的【本地配置】，
已从版本管理(git)中移除，请勿提交到仓库，避免更新冲突。

- 本目录下的文件修改后，git pull / #光遇更新 不会再覆盖或报冲突
- 若文件不存在，插件的读取逻辑会自动用内置默认值兜底
- 需要恢复默认配置时，可参考本 template/ 目录里的默认模板

template/ 目录内为本插件的【默认配置模板】，
可供参考或拷贝为正式配置使用。
